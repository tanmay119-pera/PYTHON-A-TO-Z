## 📂 Curriculum & Folder Structure

```text
PYTHON-A-TO-Z/
├── 📁 CH-1-Intro/             # Python syntax, variables, data types, I/O, operators
├── 📁 CH-2-Strings/           # Slicing, indexing, string methods & palindrome checks
├── 📁 CH-3-Tuples-Lists/      # Mutability, list/tuple methods & operations
├── 📁 CH-4-Dicts-Sets/        # Key-value maps, hashable keys, set theory (union/intersection)
├── 📁 CH-5-Loops/             # While loops, for loops, break/continue & range()
├── 📁 CH-6-Functions/         # User-defined functions, parameters, return values, lambdas
├── 📁 CH-7-Recursion/         # Base cases, recursive call stacks & algorithms
├── 📁 CH-8-File-IO/           # File read/write, with context managers & file modes
├── 📁 CH-9-OOPS-1/            # Classes, objects, __init__ constructors & attributes
├── 📁 CH-9-OOPS-2/            # Inheritance, polymorphism, encapsulation & dunder methods
├── 📁 python-Mini-Project-1/  # Real-world project 1 (Logic & State management)
├── 📁 Python-Mini-project-2/  # Real-world project 2 (Application & Data flow)
└── 📄 README.md               # Main repository documentation
```

## 🗺️ Module Breakdown

| Module / Folder | Core Topics Covered | Practice Focus (WAP) |
| :--- | :--- | :--- |
| **`CH-1-Intro`** | Variables, Data Types, Type Casting, Arithmetic, Modulo | Fee Calculator, Traffic Light System |
| **`CH-2-Strings`** | Positive/Negative Indexing, Slicing `[::]`, Built-in Methods | Palindrome Checker, Substring Counters |
| **`CH-3-Tuples-Lists`** | Mutable Lists vs Immutable Tuples, Slicing, Methods (`append`, `pop`, `sort`) | List Palindrome, Grade Sorter |
| **`CH-4-Dicts-Sets`** | Hash Maps, Unique Sets, Set Operations (`\|`, `&`, `-`), Hashability | Classroom Finder, Marks Tracker |
| **`CH-5-Loops`** | `while`, `for`, `range()`, `break`, `continue`, Nested Loops | Multiplication Tables, Pattern Printing |
| **`CH-6-Functions`** | Parameters, Default Args, `*args`, `**kwargs`, Return Statements | Factorial, Currency Converter |
| **`CH-7-Recursion`** | Call Stack, Base Conditions, Direct & Indirect Recursion | Sum of N Numbers, Fibonacci Series |
| **`CH-8-File-IO`** | `open()`, `read()`, `write()`, `append()`, `with` statement | Log Parser, Word Search in Files |
| **`CH-9-OOPS-1`** | Class vs Object, `__init__`, `self`, Instance & Class Variables | Banking System, Student Record System |
| **`CH-9-OOPS-2`** | Inheritance (Multi-level/Multiple), Polymorphism, Dunder Methods | Employee Management, Complex Numbers |
| **`Mini-Projects`** | End-to-end Python applications with interactive CLI / Game logic | Guess the Number, Task Tracker |

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/PYTHON-A-TO-Z.git
cd PYTHON-A-TO-Z
```

### 2. Navigate and Run Any Chapter
```bash
# Example: Run Chapter 1 Intro
python CH-1-Intro/main.py

# Example: Run Mini-Project 1
python python-Mini-Project-1/main.py
```
